# Storage Estimator - MB to KB and GB

## Purpose
Convert storage from MB to KB and GB.
Lab conventions: 1024 KB per MB and 1024 MB per GB.

## How to run
Requires Python 3. Run:

    python3 storage_estimator.py

## Example input and output
    Enter storage in MB: 1024
    Storage in KB: 1048576.00
    Storage in GB: 1.00
